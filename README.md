# Ezekiel G. Encila — Personal Portfolio (V2)

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Included sections
- Home / introduction
- About
- Toolkit (currently exploring + tools I use + skills)
- Projects (3 confirmed academic projects/outputs)
- Experience & involvement
- Contact

## Project included
1. ITC-C201 E-Portfolio Website — links to the live GitHub Pages project.

## Folder structure
- `index.html` — portfolio page
- `css/style.css` — theme, responsive layout, visual effects
- `js/main.js` — navigation, scroll reveals, theme toggle, certificate modal
- `assets/` — profile photo, REL artwork, DOST-PCHRD certificate
- `assets/itc-c201-portfolio-screenshot.png` — actual screenshot used for the featured ITC-C201 project
- `assets/dost-pchrd-logo.png` — supplied DOST-PCHRD logo
- `assets/dost-pchrd-certificate.jpg` — latest supplied DOST-PCHRD certificate image

## Deployment
This folder can be imported into Vercel as a static site. Use the project root as the Root Directory; no build command is required. The site entry point is `index.html`.

## Before publishing
The contact number is currently visible on the Contact section. Remove it or replace it if you do not want it publicly accessible.

The App Development academic outputs (Grade Checker and Simple Bank Account) are intentionally excluded from this portfolio version, as requested.
